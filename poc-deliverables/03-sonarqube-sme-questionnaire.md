# SonarQube SME Questionnaire

## Purpose

Use this questionnaire in a 30-minute discussion with Alex Popps and Jim Jones from Chris Greg's team. It gathers PwC-specific information that the Microsoft team cannot authoritatively provide for SonarQube.

## Licensing and cost

1. What SonarQube edition and version are in use?
2. What is the licensing model, annual cost, and renewal date?
3. Which commercial features are enabled and required?
4. What server, database, hosting, backup, monitoring, and support costs apply?

## Current usage

1. Which PwC teams, applications, and repositories currently use SonarQube?
2. Which languages and build systems are in scope?
3. Which mandatory rules, quality profiles, and custom plugins are used?
4. Which integrations exist with CI/CD, ticketing, identity, and reporting tools?

## Governance and compliance

1. Which quality gates block merges or releases?
2. Which regulatory, audit, security, or client requirements depend on SonarQube evidence?
3. Are exceptions, suppressions, and false-positive workflows governed centrally?
4. What retention, export, and audit-report requirements apply?

## Metrics and reporting

1. Is technical debt required for management reporting?
2. Are test coverage, duplication, maintainability, reliability, or security ratings mandatory?
3. Which executive dashboards and team reports are actively consumed?
4. Which metrics cannot be lost in a GitHub migration?

## Migration and decision criteria

1. What would be the minimum acceptable GitHub-equivalent rule coverage?
2. Which repositories can participate in a pilot?
3. What evidence is required before SonarQube can be retired for any team?
4. Is a hybrid operating model acceptable, and for how long?
5. Who owns the final policy and funding decision?
